# Research archive

Raw output of the verified research workflow run on 2026-09-29 (six dimensions plus four gap studies; 21 agents).

Each file contains, in order: the researcher's summary, the checkable claims it rests on with sources, the researcher's recommendations and open questions, then the independent adversarial verifier's verdict on every claim (confirmed / needs qualification / refuted / unverifiable, with corrected wording), the verifier's pushback on the recommendations, and the verifier's overall reliability assessment.

Read the verifier sections before trusting any number in the researcher sections. The synthesis that applies the verifiers' corrections is `../research-report.md`.
